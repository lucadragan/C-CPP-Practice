# C & C++ Programming Practice

A collection of programming exercises and algorithmic problems implemented in **C** and **C++**. This repository contains my laboratory assignments from the **Faculty of Applied Sciences (UPB)** as well as foundational problems practiced during high school.

## Topics Covered
* **C (University Laboratory Work):** Arrays and matrices, functions, and introductory pointer concepts.
* **C++ (High School Practice):** Control structures (`if`, `for`, `while`), basic algorithms, and vector operations.

## Repository Structure
Each source file is self-contained and named after the specific problem or algorithm it solves.
